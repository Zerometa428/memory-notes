# 拾忆 · 回忆录（本地原型）

双击 `拾忆.exe`（或同目录的 `index.html`）就能用。纯前端、零依赖、不用联网，数据存在这台电脑的浏览器里。

> 现在的状态：能写、能看、能导出；分享仅支持本机预览，不能发给其他设备访问。写的内容会自动存在本机并自动读回，导出 JSON 只是换设备或彻底清空浏览器前的保险。

---

## 一、怎么开始

1. 双击 `拾忆.exe` —— 会用一个没有地址栏、没有标签页的窗口打开（看起来像个独立小程序）；也可以直接双击 `index.html`，效果一样，只是带浏览器界面。
2. 里面已经预置了一本示例书「我的一生」：4 篇故事、5 个人物、1 个分享链接、1 条留言。可以直接改，也可以全部删掉从零写。
3. 左侧「＋ 写一篇」开始写；写完的时间点会自动落到时间轴上。

## 二、功能地图（对应《回忆录产品功能大纲》）

### 内容创作
- 篇章编辑：标题、正文富文本（加粗 / 小标题 / 引用 / 分隔线 / 插图 / 语音 / 清除格式），自动保存（右上角显示「已保存」）。
- 分卷：可在「设置 → 管理分卷」中新建、改名或删除空卷；目前还没有章管理。
- 标签：每篇可加多个标签，统计页会汇总「常写的标签」。
- 图片：正文里点「插图」上传，最长边压缩到 1280px；连了数据文件夹时直接存成图片文件，否则内嵌进数据里。
- 语音：正文里点「**语音**」选一段录音（mp3 / m4a / wav / ogg / webm 都行），会插一个播放器，图注自动写「语音 · 0:38 · 1.2 MB」。文件写到 `数据\语音\`，正文只留相对路径；单段上限 60 MB。详见下面「语音怎么存」。
- 时间：支持 日 / 月 / 年 / 季节 / 年代 / 记不清 六种精度，还能补一句口述原话（「农历六月，雨一直没停」）。
- 里程碑：勾上「标记为人生里程碑」，时间轴上会加星标。

### 时间线（灵魂功能）
- 全局时间轴：按年份分组、左侧年份轴、卡片摘要。
- 目录书本模式：像翻书一样按卷读，带点线引导和卷封面。
- 两种视图右上角一键切换。

### 语音怎么用

编辑器工具栏里点「语音」，选一个已有的录音文件（mp3 / m4a / wav / ogg 等，60 MB 以内）。
语音不会塞进数据文件里：程序版会存到 `数据\语音\`，正文里只留一行相对路径。

**放映时的节奏**：播到带语音的那一段，文字和语音一起出现，等语音放完才翻到下一块内容；
语音图注会显示在播放器下面，可以照着写一句「这是谁在说什么」。

数据\语音\演示-父亲的相机.wav 是给你听效果用的样例（系统自带中文语音合成，18 秒），
它插在「父亲的老相机」那一篇的第一段下面。
### 从头读起（整本分页阅读）
- 首页点「从头读起」，整本书会切成**一屏一页**：先是书名页，然后按时间顺序一篇篇排下去，长文自动追到下一页。
- 底部左边「← 上一页」、右边「下一页 →」；**第一页没有上一页，最后一页没有下一页**，中间的页两边都有。右上角显示「第 3 / 12 页」。
- 键盘也能翻：← → 、PageUp / PageDown、空格下一页，Esc 退出。
- 窗口改变大小时会自动重新分页（当前页码保留）。
- 排版规则：一篇文章不会从中间被切到下一页——放不下就整篇挪到下一页，所以短篇的页底会留白，这是有意的（像一本书里一篇占一页或几页）。

### 人物
- 人物卡片：名字、和你的关系、一句话印象。
- 写故事时「加一个人」把人挂到篇章上；点人物卡片能看到和 TA 有关的全部回忆。
- 「加入人物」弹窗里可以直接新建，也可以点卡片右上角的 × 删除某个人；删之前会告诉你这人挂在几篇回忆上，删完这些篇章里的引用也一并清掉。

### 地点
- 写故事时填「地点」，地点页自动按地点聚合，显示年份跨度和篇数。
- 点任意一行进入这个地点的详情页（`#/place/地点名`），列出发生在这里的全部故事。
- 地图打点需要地图服务，当前版本先做聚合列表（大纲里的离线/模糊地点已经支持：地点就是一段自由文本）。

### 分享与隐私
- 分享范围：整本书，或只挑几卷。
- 访问口令：可留空，也可设一句口令（如「老家」）。
- 分享预览：`#/s/<token>` 只在当前浏览器读取本机数据，不会把内容上传或同步给亲友，也不是独立快照。
- 可在创建时设置 7 天、30 天或长期有效；可在本机撤回或删除。口令只是本机预览门槛，不是加密保护。
- 分享页是本机全屏阅读预览：无侧栏、无编辑入口，底部留言只保存在当前浏览器，不会同步给亲友。

### 检索与统计
- 顶部搜索框：全文、人物名、地点、标签一起搜。
- 统计页：篇数 / 字数 / 照片数 / 地点数 / 人物数 / 年跨度，时间轴覆盖度柱状图（含空白年份提示）、常写标签。

### 导出与备份（刚需）
- 打印 / PDF：浏览器打印 → 另存为 PDF，已排好封面页、卷标题分页。设置页的按钮和直接按 `Ctrl+P` 都能印（打印前会自动生成排版内容）。照片会一起印出来。
- 导出网页：整本书打包成一个 `.html` 文件，图片内嵌，双击就能看，也能直接再打印成 PDF。**发给家人最推荐这个**。
- 导出 Markdown：整本书转成 `.md`，图片以 base64 内嵌（单个文件就能带走图，但文件会变大，约是原图的 1.3 倍）。
- 导出备份：整个数据库导出为 `.json`，换电脑可导入（原图、时间、人物、分享设置全在里面）。
- 回收站：删掉的篇章能恢复，也能彻底删除。

### 图片

插图就是一张图，下面不再带任何占位文字或空图注。之前版本留下的「图片说明（可点开编辑）」会在打开应用时自动清掉；如果你当时在图注里写过自己的字，那些字会留下（比如「撒旦」），只去掉占位那一截。想给某张图加图注，在编辑区里把光标放到图片后面回车，自己写一行就行。

### 氛围
- 三种纸色：纸白 / 旧纸 / 夜写（深色）。
- 衬线正文、竖排书名封面、纸纹背景。
- 写不出来时的引导问题：首页「不知道写什么？试试这些」里的五张卡片，点进去会直接建好一篇——标题已填，三个引导问题放在正文的引用块里，边写边删。

## 三、数据存在哪

### 用 `拾忆.exe` 打开（推荐）：程序自己存文件，零点击

双击 `拾忆.exe` 时，程序会在自己旁边建一个 `数据/` 文件夹，里面就是 `回忆录数据.json`：

- **不用连接、不用授权、不用点任何按钮**。改一个字约半秒后自动写进那个文件；关窗口前再补写一次。
- 打开时如果浏览器配置里还没有内容，会**自动从这个文件读回来**（实测：把 `用户数据/` 整个删掉再启动，11 篇内容原样回来）。
- 每次覆盖前会把上一版留成 `数据/回忆录数据-上一版.json`，误删内容时可以从这里捞。
- 设置页「数据文件夹」那行现在只显示「**自动保存中**」和文件路径，没有授权按钮了；顶部那条「连接文件夹」提示条在程序版里直接不出现。
- 侧栏底部显示的是「**数据文件 1.59 MB**」——就是那个 json 的体积，不带 5 MB 配额条。
- 浏览器缓存（localStorage）写满也不影响保存：内容会照常写进数据文件，不会弹「保存失败」。
- 换电脑：把**整个文件夹**拷过去就行（exe + 网页 + `数据/` + `音乐/`）。

### 用浏览器直接打开 `index.html`：浏览器一份 + 文件夹一份

这条是为「不装程序、直接开网页」准备的，程序版用不到。

默认就存浏览器里，**不用点任何按钮**。想另外落一份到硬盘时，页面顶部会出现一条提示：

> 浏览器里存一份，也往项目里的「数据」文件夹存一份 —— 点一下授权，之后全自动

点「**连接文件夹**」，在弹窗里选中项目里的 `数据` 文件夹，之后就再也不用管了：

- 你的内容会写成 `数据/回忆录数据.json`，是真实文件，资源管理器里能看到，能复制、能用网盘同步。
- 平时编辑**先存浏览器**，停顿约 1 秒再写进那个文件；关页面时补写一次。
- 下次打开，如果浏览器还记着授权，就**自动读文件**，两边始终一致；忘了授权就在顶部提示你点一下。
- 文件夹里已经有数据时，连接那一刻会问你：用文件夹里的，还是用当前页面覆盖文件。
- 编辑器右上角从「正在保存…」变成「**已存到文件夹**」，表示真的落盘了。

> 为什么非要你点这一下：浏览器不允许网页自己往硬盘任意位置写文件，必须由一次点击授权。这是安全限制，绕不过去。这也是为什么程序版另走一条路——宿主程序直接替你写文件。

不想连也行，点提示条右边的 `×`，以后就只存浏览器里，不再打扰。

### 浏览器里那一份是什么

- 存在 `localStorage`，键名 `shiyi.memoir.v1`，上限约 5 MB。
- **不用手动保存**：改一个字就自动存一次（编辑器右上角显示「正在保存…／已保存在本机」），下次打开自动读回来。
- 每次保存还会异步镜像一份到 IndexedDB（键 `shiyi.memoir.bak`）：万一 localStorage 被浏览器清掉，打开时会自动从这份备份恢复，并弹一句「已从自动备份恢复上次写的内容」。启动时还会向浏览器申请「持久化存储」，降低被自动清理的概率。
- 侧栏底部那行：**浏览器版**显示「本地存储 1.59 MB · 31.8%」并带配额条（按 UTF-8 字节算，超过 80% 变红）；**程序版**改显示「数据文件 1.59 MB」、不画配额条——因为真正的家是硬盘上的 `数据\回忆录数据.json`，**硬盘多大就能存多大**，浏览器那 5 MB 只是缓存。
- 照片默认走 base64 存进同一个地方，是最占空间的；**连上数据文件夹后会自动改成存文件**（见下节），浏览器里那份就不再涨。
- 5 MB 纯文本能写非常久（一千字才 3 KB 左右），真正吃满的一定是照片。

### 语音怎么存

正文里点「**语音**」，选一段录音文件就行（不支持麦克风现场录，只导入已有文件）。插入后是这样：

```
<figure class="audio"><audio controls src="数据/语音/s9-mw26hjnl.m4a"></audio>
<figcaption>语音 · 0:38 · 1.2 MB</figcaption></figure>
```

- **程序版**：文件直接写进 `数据\语音\<篇章id>-<时间戳>.<扩展名>`，正文只留路径，所以那个 json 几乎不涨。
- **浏览器版（连了文件夹）**：同样写进文件夹里的 `语音/`。
- **浏览器版（没连文件夹）**：只能内嵌成 base64 塞进数据里——一段 1 分钟的 m4a 大约让数据涨 1 MB，不建议。
- 图注是可以点的，想改成「妈 1998 年唱的那支歌」直接改文字就行。
- 单段上限 60 MB；超过会提示先剪一段。
- 播放器在阅读页、分享页、从头读起里都能直接播；打印/PDF 里会隐藏播放器、只留一行「（语音）图注」。
- 星图放映目前只播文字和图片，**语音不会自动播放**。

### 照片存成文件（连上文件夹之后）

连上数据文件夹后，插图不再塞进正文里，而是：

1. 照片写成 `数据/图片/<篇章id>-<时间戳>.jpg`
2. 正文里只留一行相对路径：`<img src="数据/图片/e7-ab12x9.jpg">`

所以浏览器里那份几乎不再增长，**几百张照片也放得下**，原图质量也不损失（仍然是长边 1280 压缩，但不受 5 MB 限制）。

- 设置页「数据文件夹」那行多了个「**把照片移进文件夹**」：把所有已经以 base64 存着的照片搬到 `数据/图片/`，正文就地改成引用文件。搬完浏览器占用会明显下降。
- 导出（网页 / Markdown）时会自动把文件夹里的图片读出来、内嵌进导出文件，导出的东西依旧是单个文件、双击能看。没连文件夹时会提示「有照片还指向文件夹，导出文件里看不到那几张」。
- **备份 JSON 里存的是相对路径**，换电脑时要把 `数据/` 整个文件夹一起拷走，单拷那个 JSON 会丢图（网页/Markdown 导出不受影响，图是内嵌的）。
- 星图、翻页、打印、分享页都用同一个相对路径读图，无需额外操作。

## 四·五、星图时间线（另一个版本的时间线，可选用）

双击 `星图时间线.html` 打开（或者从首页点「回忆时间线」进入），是一个**独立的试验页**，不修改原来的任何文件。从首页进入时只会保留一个窗口：**上次那个没关，再点就把它顶掉并重新放映**，不会攒一堆标签页：

- **开场**：四散的光尘收束成一个时间节点，闪一下，中间的星轴向两边铺开，一篇篇回忆像星星一样旋转着散到星轴四周（立体排布，有地面投影、倒影和光晕）。右上角「重播开场」可以再看一遍。
- **穿行时间**：滚轮或左右拖动沿时间前后走；上下拖动可以转动星轴；← → 逐篇跳；停下来会轻轻吸附到最近的一篇。
- **折叠**：焦点附近的几篇完全展开，越远越压缩——往后走，前面的篇章会合拢成星轴上的一圈圈细环；往前走，后面的同理。两端的「更早 / 更晚 · N 篇」可以点。
- **无限长**：时间轴两头都能一直走下去，「此刻」之后是虚线和「未写」的年份；底部的整体时间尺显示整本书和当前展开的位置，可以直接拖。
- **内容**：内置了一份完整的回忆录（1981 年那场雪到 2026 年开始写这本书，约 40 篇，和应用里的种子内容是同一个人）。如果你在应用里写过或改过，会自动合并进来，同一篇以你的版本为准。
- **改一篇**：双击卡片，或点右侧详情面板里的「编辑这篇」，会直接跳回应用里的编辑器打开这一篇，改完保存就在原地生效。
- **跟着应用变**：读的是同一份数据。在应用里删掉的篇章（进回收站）这里不再显示；在应用里改完切回这个标签页，会自动重排——不用手动刷新。
- 点星星打开右侧详情，可以上一篇 / 下一篇。系统开了「减少动态效果」时会跳过开场动画。

## 四·六、进入星图时的「放映」

打开 `星图时间线.html` 会先放一场放映，再落到星图上：

- **顺序**：按时间从最早一篇到最后一篇，逐篇过。
- **一篇之内**：按原文的顺序走——先出这一段文字，停一会儿；遇到照片就单独淡入一张（文字先淡出），停一会儿再淡出；然后接着放照片后面的文字。所以「文字 → 图片 → 文字」会照原样顺序播，图片不并排、不扎堆。
  一段连续的文字最多分 3 个段落一屏；这一篇放完，整屏淡出，下一篇淡入。
- **进度**：底部一条细线显示整场进度，右下角是「第 3 / 12 篇」。
- **跳过**：右下角「跳过 ›」、按 Esc、或者点卡片外面的任何地方，立刻结束放映回到星图。
- **节奏**：正文停留时间跟字数走（越长越久）；篇数超过 12 篇会自动提速，免得开场太长。
- **重看**：右上角「从头放映」可以随时再放一遍；「重播开场」只重放星图自己的聚拢动画。
- **背景音乐**：放映一开始就放，循环，音量压得很低，不抢内容；放映结束或跳过后淡出。右下角「♪ 音乐」可以随时静音/恢复，选择会记下来。
- **自动出声（推荐从首页进）**：从 `index.html` 首页点「回忆时间线」进星图时，音乐由**原来那个窗口**代播——它刚被你点过，浏览器允许它出声，所以星图一打开就有音乐，不用再点。星图窗口自己是被新开的，没有点击手势，浏览器不许它自动发声音，这是分窗口的关键差别。
  直接双击 `星图时间线.html` 打开（没有来源窗口）时，仍然需要点一下页面。
- **右下角那行小字会说明音乐状态**（放映时显示在按钮左边）：
  - `♪ 主窗口在播 · 音量 50%（右边会写明当前音量）` —— 正常，声音来自首页那个窗口；
  - `♪ 主窗口被拦，点一下页面` —— 浏览器拦了，点一下星图任意位置，改由星图窗口自己放；
  - `♪ 主窗口没回应（刷新一下首页）` —— 首页那个标签页是旧版本，按 Ctrl+F5 刷新首页再点一次；
  - `♪ 音乐已关（点右下角打开）` —— 你之前把音乐关了，点一下「♪ 静音」那个按钮恢复；
  - `♪ 被拦，点一下页面` —— 直接打开的星图被拦了，点一下即可；
  - `♪ 本窗口在播` —— 星图窗口自己在放；
  - `♪ 合成音在播` —— 没找到音频文件，退回内置合成音。
- **系统开了「减少动态效果」时**：不再播放放映画面（避免不适），但**音乐照样会放**。
- **换成《风之谷》钢琴曲**：把音频文件命名成 `风之谷.mp3` 放进 `音乐/` 文件夹（或 `数据/音乐/`），再打开星图就自动用它。也认 `.m4a`、`.ogg`、`.wav`。
  不想改文件名，就在放映时点右下角「**♫ 换曲**」选一次；那时若已连上数据文件夹，文件会被存进 `数据/音乐/`，下次自动用这首（没连则只在本次有效）。
- 找不到音频文件时退回页面合成的四小节和弦（WebAudio 现场生成、不带文件），保证不会没声音。
- **「一进来就有声音」这件事**：浏览器默认拦截没有用户操作的自动播放，这是规定。现在的做法和边界：
  1. **从首页点「回忆时间线」进**：主窗口代播，**进去就响，零点击**（已实测）；
  2. 直接双击星图文件打开：一进页面立刻尝试，被拦时中间会出现「♪ 点一下页面任意位置，音乐就开始」，随便点一下（或按任意键）立刻响；
  3. 零点击：用 **`拾忆.exe`** 打开——它内嵌的浏览器一开始就允许自动播放，进星图就自己出声（右下角显示「♪ 本窗口在播」），不需要「从首页代播」那一套。
- 也可以给地址加参数指定曲子：`星图时间线.html?bgm=我的曲子.mp3`。
- 放映结束后星图会自己再聚拢一次，衔接比较顺。系统开了「减少动态效果」时自动跳过放映（想看得点「从头放映」）。

## 四·七、双击 `拾忆.exe`（单文件独立程序）

双击 `拾忆\拾忆.exe`，会开一个**自己的窗口**：没有地址栏、没有标签页、没有浏览器工具栏，就是一个 WinForms 程序，窗口里嵌 WebView2 显示这个回忆录。任务栏图标是深棕底 + 红印章「拾」。

- **只有一个 exe**。WebView2 需要的两个托管 DLL 和 `WebView2Loader.dll` 都打包在 exe 里面，运行时自己解到同目录的 `运行库/`（第一次启动自动生成，删了也会重建）。不用再放三个 DLL 在根目录。
- **只有一个窗口**。点「回忆时间线」是**在这个窗口里切换过去**，不再另开一个窗；星图右上角的「回到应用」切回主界面，回到时间线那一页。所以主窗口不会在后台继续放音乐——切换时主页面已经卸载了，只剩星图自己在放。
- **放映音乐零点击**：程序给内嵌浏览器开了「允许自动播放」，星图一打开就自己放《风之谷》，右下角显示「♪ 本窗口在播」。
- **数据放在 `数据/回忆录数据.json`**：程序启动就建好 `数据/`，页面通过宿主通道直接读写这个文件，**不需要连接文件夹、没有任何授权弹窗**。每次覆盖前会留一份 `回忆录数据-上一版.json`。`用户数据/` 是浏览器内核自己的配置目录（localStorage 在里面），只是副本，删了也能从文件恢复。
- **换电脑 / 备份**：把 `拾忆\` **整个文件夹**拷走（`拾忆.exe`、`index.html`、`app.js`、`styles.css`、`星图时间线.html`、`数据/`、`音乐/`、`用户数据/`）。`运行库/` 不用拷，会自动生成。
- **依赖**：Windows 10/11 自带的 WebView2 运行时（本机已装 156.x）。精简系统没有的话，搜「WebView2 Runtime」装一次。
- **不写注册表、不装服务**：不想用了，直接删整个文件夹。
- 想排查：文件夹里放一个 `调试.txt`，程序会开本机 `http://127.0.0.1:9333` 调试端口；删掉就没有。

## 五、文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面外壳，双击它 |
